# LMS Frontend

This is the frontend for the Loan Management System, built with Next.js, TypeScript, and Tailwind CSS.

## Setup

For detailed setup instructions, please refer to the main [README.md](../readme.md) in the project root.

## Quick Start

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Build

```bash
npm run build
npm start
```

## Environment Variables

Required environment variables (see `.env.local`):
- `NEXT_PUBLIC_API_URL`
- `GOOGLE_CLIENT_ID`
- `GOOGLE_CLIENT_SECRET`
- `NEXTAUTH_SECRET`
- `NEXTAUTH_URL`

See [../readme.md](../readme.md) for configuration details.
